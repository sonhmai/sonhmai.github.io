# Editing the site

See [README.md](README.md) for setup, content editing, analytics, and GitHub Pages publishing.

The Jekyll source folders are retained as a migration reference. Edit `src/content/posts/` for current articles and `public/` for assets.

Run `npm run build` and `npm run audit` before publishing. The migration inventory checks content against the original sources, so intentional article edits require reviewing and updating that comparison.
